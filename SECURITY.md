# Política de seguridad

## Versiones con soporte
Solo se da soporte a la versión más reciente publicada en [Releases](https://github.com/Altem1/UkiList/releases).

## Reportar una vulnerabilidad
**No abras un issue público.** Repórtala de forma privada desde la pestaña
[Security > Report a vulnerability](https://github.com/Altem1/UkiList/security/advisories/new).

Incluye:
- Descripción del problema y su impacto.
- Pasos para reproducirlo.
- Versión de UkiList afectada.

Recibirás respuesta lo antes posible. Si se confirma, se corregirá en una nueva versión y se te dará crédito si lo deseas.

## Alcance
- Tu sesión de AniList se guarda cifrada en el dispositivo y nunca se envía a otros servidores.
- Las claves de Google heredadas del proyecto original UKIKU no pertenecen a este repositorio.
